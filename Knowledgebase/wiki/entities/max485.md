# MAX485-M

RS485 transceiver type named in [[sources/project-brief]]; couples [[entities/esp32-s3-wroom-1]] to the Daikin bus ([[concepts/bus-topology]], [[concepts/modbus-rs485-link]]).

## Module facts ([[sources/max485-module-photo]], photo read visually)
- "MAX485-M" is a **breakout board** (small blue PCB), not a bare chip.
- U1 is an SO-8 IC with an **illegible marking**: chip type and manufacturer unconfirmed (MAX485 assumed from the name; MAX3485/SP485 not excluded).
- Logic header: **RO, RE, DE, DI**, with DE and RE on **separate pins**; no auto-direction circuitry visible *(inferred from absence on the top side)*. The firmware/wiring must drive DE and RE (or tie them together, see chip facts).
- Bus side: right header with "GND" readable (rest VCC/A/B *inferred*), 2-pole screw terminal (A/B *inferred*).
- **Termination: none on board** (user statement, session 2026-11-07, not in raw: "I had to buy a 120 ohm separately, it is not on the board by default."). The user has a separate 120 Ω resistor; its placement depends on the existing bus termination ([[concepts/bus-topology]] open item 3).
- **Conflict:** the photo shows R7 with code read as "121" (120 Ω, medium-high confidence), which was *inferred* to be an A-B termination ([[sources/max485-module-photo]]). The user statement wins for the termination question; R7's role or the code reading is **unexplained**.
- R5/R6/R8 possibly bias resistors *(inferred, unverified)*. D1 possibly a power LED *(inferred)*.
- **Supply voltage not determined**: no 5V/3.3V marking visible.

## Chip facts ([[sources/max485-datasheet]])
- Half-duplex RS-485 transceiver, supply **5 V ±5 %**, 2.5 Mbps (far above the 9600 baud Modbus link), 1 unit load.
- Pins: 1 RO, 2 /RE, 3 DE, 4 DI, 5 GND, 6 A, 7 B, 8 VCC. DE high = transmit, /RE low = receive (p7, p10).
- Inputs accept 3.3 V logic (V_IH ≥ 2 V), but **RO outputs ≥ 3.5 V (5 V level)** while the ESP32-S3 is 3.3 V logic → level shift needed (inferred). See [[entities/esp32-s3-wroom-1]]. Still open: the module's supply is unknown, and if U1 were a 3.3 V part (e.g. MAX3485) the concern would not apply *(inferred)*.
- Line terminated at both ends in its characteristic impedance; the 120 Ω value comes from the figures; keep stubs short (p13).
